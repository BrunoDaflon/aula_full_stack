[Pessoa cliente / atendente]

    É quem utiliza o sistema. A cliente registra e acompanha chamados, enquanto o atendente consulta, atualiza e encerra os chamados após conclusão.

[Interface Web / Front-end]
    
    É a parte visual que a pessoa utiliza para interagir com o sistema. Por exemplo, telas de login cadastro de chamados e consulta dos chamados.

[API]
    
    É o ponto de comunicação entre o front-end e o back-end. Recebe as solicitações da interface e encaminha para o sistema.
